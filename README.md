m_hosary bot
===============

Telegram-бот для генерации аудиофайлов с чтением Корана (Махмуд Аль-Хусари), с возможностью выбора сур и аятов, установки цветового маркера и публикации в канал.

* * *

📦 Функционал
-------------

*   Генерация аудиофайлов выбранной суры и диапазона аятов.
    
*   Автоматическая обработка и добавление ID3 тегов к mp3.
    
*   Отправка аудио с подписанным сообщением в Telegram-канал.
    
*   Поддержка выбора цвета (эмодзи) перед публикацией.
    
*   Сохранение данных отправленных аудио (file\_id, сура, аяты, цвет, дата).
    
*   Очистка временных файлов и сброс текущих данных.
    

* * *

⚙️ Установка
------------

1.  Клонировать репозиторий:
    

bash

`git clone https://github.com/ваш-репозиторий/quran-bot.git cd quran-bot`

2.  Установить зависимости:
    

bash

`npm install`

3.  Создать файл `.env` с переменными:
    

env

`BOT_TOKEN=ваш_токен_бота CHANNEL=ID_вашего_канала ALLOWED_USER_ID=ваш_telegram_id`

4.  Убедиться, что папка `temp` существует (бот создаёт её автоматически при запуске, если отсутствует).
    

* * *

📝 Использование
----------------

### Команды

*   `/surah <номер>` — установить номер суры.  
    Пример:
    
    bash
    
    `/surah 5`
    
*   `/clear_all` — сброс всех текущих данных и очистка временной папки.
    

* * *

### Работа с ботом

1.  Отправьте номер суры командой `/surah`.
    
2.  Отправьте диапазон аятов в виде текста, например:
    

`1-5,7,10`

3.  Бот предложит выбрать цвет (эмодзи).
    
4.  После выбора цвета бот отправит аудио с кнопками:
    
    *   ✅ Отправить в канал
        
    *   ❌ Отменить
        
5.  После отправки аудио данные будут сохранены в `audio_data.json` для дальнейшего использования.
    

* * *

🔧 Зависимости
--------------

*   [telegraf](https://www.npmjs.com/package/telegraf) — Telegram API.
    
*   [node-id3](https://www.npmjs.com/package/node-id3) — работа с ID3 тегами mp3.
    
*   [fluent-ffmpeg](https://www.npmjs.com/package/fluent-ffmpeg) — конвертация и обработка аудио.
    
*   [ffmpeg-static](https://www.npmjs.com/package/ffmpeg-static) — встроенный ffmpeg.
    
*   [winston](https://www.npmjs.com/package/winston) — логирование.
    

* * *

⚠️ Важно
--------

*   Бот доступен только для пользователя с `ALLOWED_USER_ID`.
    
*   Временные файлы создаются в папке `temp` и удаляются после отправки или отмены.
    
*   Аудио сохраняется с тегами: название суры, автор и год.
    
*   Диапазоны аятов проверяются на корректность, 0 или несуществующие номера аятов запрещены.
    

* * *

📌 Логирование
--------------

*   Логи записываются в консоль и файл `bot.log`.
    
*   Логируются ошибки, успешные отправки и действия пользователя.
    

* * *

🚀 Запуск
---------

bash

`node bot.js`
